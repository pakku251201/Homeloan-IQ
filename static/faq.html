Is this a real AI model?

No. The current checks are deterministic JavaScript rules. “Agent” labels describe workflow roles, not a deployed LLM.

Does it connect to CIBIL or CERSAI?

No. These are synthetic/mock records. There are no live external-service calls.

Does BigQuery store the data?

The loader is designed to create six source tables, a joined applicant view and a decision log in the configured Google Cloud project. Verify table/view counts and the app's Load from BigQuery button before claiming live integration.

Can the system approve a loan?

No final sanction should be made by this demo. It gives a rule-based recommendation; an authorised officer makes the final decision.

Are the policy thresholds official?

Some UI thresholds are illustrative. Check the cited official RBI material and the relevant lender's current policy before treating any threshold as authoritative.

Why does it sometimes generate sample applicants?

The page falls back to synthetic sample records if the BigQuery API cannot return data, so the UI can still be demonstrated offline.
