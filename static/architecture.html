Controls and boundaries

  • Only synthetic applicant data and mock external responses.
  • Explicit, deterministic checks; reasons are displayed alongside policy labels.
  • Officer decision is separate from the system recommendation.
  • BigQuery integration is optional for local fallback, but the live data path must be verified before presenting it as working.
  • No OCR, vector retrieval, live bureau/CERSAI APIs, authentication or production security in this prototype.
Next production controls
